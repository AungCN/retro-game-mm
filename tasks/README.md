# Phase Task Directory

Each phase file is a bounded work package. Read it together with `AGENTS.md`, `GOALS.md`, `PLANS.md`, and relevant docs.

## Workflow for each phase

1. AI performs discovery and prepares a plan.
2. Owner reviews and records explicit approval.
3. AI implements the approved plan only.
4. AI runs checks and submits an implementation report.
5. Owner evaluates the actual result.
6. AI corrects findings after approval.
7. Owner records acceptance and authorizes the next phase.

Do not skip gates. Use `EVALUATION_TEMPLATE.md` for the human review record.
