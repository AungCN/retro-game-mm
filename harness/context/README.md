# AI Context Notes

Use this folder only for concise, non-sensitive project context that helps a coding agent resume work. Keep authoritative requirements in `docs/`, not in chat transcripts.

Suggested files:
- `CURRENT_STATE.md` — current accepted phase, branch, latest accepted commit, and known blockers.
- `OPEN_QUESTIONS.md` — unresolved owner decisions.
- `GLOSSARY.md` — project terms and game-specific vocabulary.

Do not put credentials, access tokens, private user data, or copied copyrighted assets here.
