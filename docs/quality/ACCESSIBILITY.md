# Accessibility Checklist

## Platform interface

- [ ] Semantic headings, landmarks, buttons, and links
- [ ] Full keyboard navigation for catalogue and settings
- [ ] Visible focus indicators
- [ ] Descriptive accessible names for icon-only controls
- [ ] Text contrast and control contrast reviewed
- [ ] Status not conveyed by color alone
- [ ] Text resizing/zoom does not break primary flows
- [ ] Reduced-motion preference respected by platform UI
- [ ] Loading and error messages announced appropriately
- [ ] Touch targets usable on small screens

## Game interface

- [ ] Controls documented before play
- [ ] Pause/exit behavior available and discoverable
- [ ] Game does not trap keyboard focus
- [ ] Input does not rely exclusively on color or sound where alternatives are practical
- [ ] Motion/flash effects reviewed
- [ ] Difficulty or sensitivity options considered where appropriate
- [ ] Touch controls do not obscure essential gameplay
- [ ] Game-specific limitations documented honestly

## Review

Accessibility is evaluated for both the platform shell and each game. A passing automated scan is not a substitute for keyboard, zoom, and manual usability checks.
